# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Projet

Vektor (ex-Illu) : outil web d'illustration vectorielle générative (esprit « Retro Futuristic Elements »). On compose des formes sur des calques ; chaque calque porte une pile de modificateurs (pas, miroirs, axial, spirale) qui le duplique, et une pile d'interpolations qui fait varier opacité/échelle le long des copies. Export SVG, sauvegarde JSON.

Écarts avec le brief initial — ce qui fait foi est le code :
- **Pas de p5.js.** Rendu en SVG DOM direct (`#stage` dans `index.html`). Un seul moteur de rendu : le `<svg>` à l'écran est à la fois l'aperçu et la source de l'export, il n'y a pas de `renderer-canvas.js`.
- **Plusieurs modificateurs par calque** (`layer.modifiers[]`, empilés), plusieurs formes par calque (`layer.elements[]`), interpolations empilées (`layer.interpolations[]`). Une forme porte aussi les siennes (`element.modifiers[]`, `element.interpolations[]`, depuis `@25`), cumulées avec celles du calque.
- Vanilla JS (ES modules), Vite, Vitest. Interface et commentaires en français.

## Commandes

`pnpm` uniquement (scripts de cycle de vie bloqués, cf. `pnpm-workspace.yaml`).

```sh
pnpm dev                          # Vite sur http://localhost:5173
pnpm build                        # dist/
pnpm test                         # vitest run (tout)
pnpm test test/core.test.js       # un fichier
pnpm test -t "axial"              # tests dont le nom contient « axial »
```

Pas de linter ni de formateur configuré.

## Architecture

Flux unidirectionnel : **transition pure → store → render**.

- `src/scene.js` — modèle + **toutes les transitions**, immuables, signature `(scene, ...args) -> scene`. Renvoyer la même référence = geste sans effet, le store ne notifie pas. Contient aussi les sources uniques : `SHAPES`, `RANGE_BOUNDS`, `STAGE`, `getRenderedChildren(layer)`.
- `src/store.js` — store minimal ; l'UI appelle `store.apply(transition, ...args)`, jamais de mutation ni de type d'action. Porte l'historique (pile de scènes, `HISTORY_LIMIT`) : un changement de sélection seule n'y entre pas, `begin(key)`/`end(key)` regroupent un geste continu en un pas — câblés au niveau du document dans `ui/history.js` (pointerdown→pointerup, input→change).
- `src/modifiers.js` — un modificateur transforme **un point** `(point, i, n, center, options) -> {x, y, angle, flip}`, appliqué au calque entier (le motif bouge en bloc). `angle`/`flip` = orientation de la copie, composée dans `applyStack` si `orients(modifier)` (case « Orienter les copies », défaut actif sur miroirs/axial/spirale), puis ajoutée à la rotation propre dans `getRenderedChildren`. Les transformations doivent rester des similitudes, sinon le motif se disloque copie après copie. Pile = produit cartésien des indices (`stackCopies`), appliquée dans l'ordre (`applyStack`) — l'ordre change le dessin. `FIXED_COPIES` : miroirs = 2 copies, `none` = 1. Axe d'un miroir : `modifier.axis` (degrés, `clampAxis` → [0, 180)) sinon `MIRROR_AXIS` du type (mirrorH 90°, mirrorV 0°) ; changer de type le retire. Pivot : `modifier.center` (optionnel, types de `PIVOTING`) sinon `layer.center`, y compris pour un étage de forme — `pivotOf(layer, index, owner = layer)` dans `scene.js` est la source unique (rendu des repères, glisser via `data-pivot` (`ui/gestures.js`) + `data-pivot-owner` pour un étage de forme, panneau).
- Piles de forme : appliquées **avant** celles du calque (`applyStack` chaîne l'orientation), copies = produit ; `copyTotal(layer)` = copies du calque × Σ copies propres des formes, borné par `MAX_COPIES` (`isSuspended`). Enfant rendu : `copy` (rang calque) et `own` (rang propre) ; booléens et formes logées s'apparient sur les deux, repli sur `own = 0` (`renderer-svg.js`). Les transitions de pile (`addModifier`, `updateInterpolation`…) prennent l'id d'un calque **ou** d'une forme (`mapOwner`). UI : `ui/modifier-section.js` et `ui/interpolation-section.js` montés deux fois (calque, forme) avec un `ownerOf`, briques DOM dans `ui/fields.js`.
- `src/interpolate.js` — rampe `t(i, n)` partagée (garde n ≤ 1 → 0, seul endroit), `clampCount` (n ≥ 1). Deux interpolations de la même propriété se composent **par produit** (neutre = 1), sauf les propriétés `additive` de `RANGE_BOUNDS` (rotation : somme, neutre 0) et `color` (plage de deux `#rrggbb`, `lerpColor`, la dernière de la pile l'emporte ; remplace la couleur de la forme sur trait et aplat). L'épaisseur interpolée est un facteur de celle de la forme ; `scaleX`/`scaleY` (depuis `@27`) étirent `rx`/`ry` et les sommets d'un tracé dans le repère de la forme (`stretch`, polygone/arc ne lisent que `rx`) ; `dashOffset` (additive) = `stroke-dashoffset` en multiples de l'épaisseur × échelle. Courbe `random` (depuis `@27`) : bruit haché `noise(i, seed)`, graine `interpolation.seed` tirée par l'UI (`randomSeed`, bouton « Relancer »), transitions pures. `binding` = rang d'un modificateur de la pile de son propriétaire (la rampe ne suit que cet étage) ou `null` (rampe sur le total des copies de cette pile). Interpolations de forme composées après celles du calque (la couleur de la forme l'emporte). Réordonner/supprimer un modificateur doit remapper les bindings (`remapBindings` dans `scene.js`).
- `src/renderer-svg.js` — `render(scene, svgRoot)` reconstruit le SVG depuis `getRenderedChildren`, plus les repères (`data-guides`) du calque actif et le cadre pointillé de sélection (`data-selection` : boîte de la copie source de la forme, ou de tout le calque sans forme sélectionnée ; `childBounds` la calcule sans `getBBox`). `toSvgDocument` clone le DOM et retire repères/survol pour l'export.
- `src/persistence.js` — `serialize`/`deserialize` + autosave localStorage (debouncée dans `main.js`). Format versionné (`FORMAT = 'vektor/scene@N'`, anciens `illu/scene@N` jusqu'à `@16`) : **tout changement du modèle** doit bumper le format et garder les anciens lisibles (`READABLE_FORMATS` + lecture legacy), import validé et borné champ par champ. `STORAGE_KEY` (`illu:scene:v1`) et `illu/settings` gardent l'ancien nom, exprès.
- `src/ui/*` — interface « design E » (panneaux flottants sur le plan plein écran : arbre calques → formes à gauche, réglages du calque OU de la forme à droite, outils en bas) ; panneaux DOM montés par `main.js` (`mount*({ store, container, ... })`), qui s'abonnent au store. Helpers communs dans `ui/list.js` (reconstruction en gardant le focus, `whenChanged`) ; contrôles de formulaire (`bindControl`, `segmented`, `slider`, `field`…) dans `ui/fields.js`, seul module du genre. Panneau de droite = `property-panel.js` qui assemble `shape-fields.js`, `stroke-fields.js`, `plane-fields.js` et les sections. Toolbar : gestes au pointeur dans `ui/gestures.js` (un geste = `{ move, end, cancel }`, un seul à la fois), menu Exporter dans `ui/export-menu.js`. Sections repliables (`collapsible` dans `ui/fields.js`) : état par clé (`repeat`, `interpolations`, `booleans`) partagé calque/forme, dans `illu/settings.collapsed` (`settings.js` réécrit le seau par fusion).

Conventions du modèle :
- Style (couleur `stroke`, `strokeWidth`) sur la **forme** (depuis `@20` ; avant, sur le calque — relu en le recopiant sur chaque forme). Une nouvelle forme reprend `filled`/`stroke`/`strokeWidth` de la forme active ; sans forme active, `stroke`/`strokeWidth` viennent du style courant `scene.style` (carte du trait, `setStyle`/`currentStyle`, non sauvegardé, hors historique), `filled` de la dernière du calque (`addElement`). `filled` = rempli de la couleur de la forme ; style de trait `dash` (multiples de l’épaisseur × échelle de la copie), `linecap`. Contour double (`outlined`, `gap`, depuis `@22`) : trait élargi à `2·strokeWidth + gap·échelle de la copie` évidé par un masque (`hollowStroke`), sauf le point.
- Plan 3D (depuis `@23`) : `layer.plane` = `null` (jamais activé) ou `{ enabled, tilt, heading, sides }` — éteint, il garde ses réglages ; lire le plan effectif par `activePlane(layer)`, bascule `togglePlane` (cube dans l'arbre), appliqué **après** la pile de modificateurs, projection orthographique autour du centre de la scène (`src/plane.js` : `planeMatrix`, `unproject` pour le pointeur dans `toolbar.js`). Sur un calque en plan, `createNode` émet un `<path>` projeté depuis `outlinePath` (le trait n'est pas écrasé). La première activation (`DEFAULT_PLANE` 45°/45°) donne `DEFAULT_DEPTH` (80) aux formes sans profondeur, et `addElement` aux nouvelles formes d'un calque en 3D. `element.height` (≥ 0, « Profondeur ») = extrusion le long de la normale, centrée sur le plan (`createShape` décale de −v/2, `createExtrusion`) : face arrière + arêtes de silhouette/coins masquées par l'aire de la face avant ; `sides: 'filled'` peint le volume de la couleur pleine de la forme. Contour double fermé = anneau : ses deux traits décalés dans le repère du plan puis projetés (`planeDouble`), le séparateur s'écrase avec la perspective ; contour double ouvert (ruban, ligne, arc) = ses deux traits décalés dans le plan aussi (`planeBand`), extrudé comme une bande pleine entre eux (`openBand`). Forme simple = prisme plein, pas d'extrusion sous booléen. Volume qui se cache lui-même (ruban, tracé ouvert, étoile, tracé fermé non convexe) : arêtes du fond et de flanc découpées par la géométrie dans un masque (`createWalls` : `backRuns`, `flankRuns` — en projection parallèle, caché = une paroi passe devant à l'écran), sans ordre du peintre ; ceux d'un même calque et de même extrusion se découpent aussi l'un l'autre (`wallNeighbours` : rubans d'une spirale répétée en axial), et une forme logée dans un ruban répété est cachée par toutes ses copies propres ; bords d'une bande débouclés là où le tracé tourne plus serré que son décalage (`untangle`) ; convexe, moitié proche du fond seule. Occlusion entre volumes par l'ordre de dessin (scène entière) : chaque volume fermé (`occluder` dans `plane.js`) masque ce qui est dessiné avant lui, sauf à travers le trou d'un anneau — masques chaînés dans `<defs>` (`occlude`, `src/renderer-plane.js`, qui porte aussi `createShape`/`createExtrusion`/`createPlaneDouble`).
- Répétition linéaire (depuis `@24`, pile du point depuis `@25`) : portée par l'étage, pas par le point : un point est remplacé par un tracé `polyline` reliant ses copies le long des étages `modifier.linear` de **sa propre** pile (l'axial se referme) — `linkPoints` dans `scene.js`. `modifier.smooth` (depuis `@26`) : tracé qui suit la transformation exacte de l’étage à indice fractionnaire (`sweep`, arc de spirale/cercle exact passant par les copies), reste une `polyline` pour le 3D/contour double. Les étages du calque ne relient jamais (`linear` retiré à la lecture), chaque copie du calque porte ses tracés. Plus de `element.linear` (ignoré à la lecture).
- `x, y` = centre de la forme, `rx, ry` = demi-extensions (signées seulement pour `line`, via `clampExtent`). Le « point » est une ligne de longueur nulle à bout rond, dimensionné par l'épaisseur.
- Le tracé (`polyline`) porte `points` relatifs à `x, y`, recentré sur sa boîte englobante (`recenterTrace`) après chaque geste. Import collé par `src/path.js` (courbes C/S/Q/T/A échantillonnées en sommets, borné par `MAX_POINTS`). Poignées de sommets (`data-handles`) = état d'écran, retirées à l'export comme les repères.
- Forme logée : `element.inside` = id d'une forme **fermée** (`isClosedShape`, y compris un point à étage linéaire : anneau ou ruban) du même calque, ou `null` ; `setInside` refuse soi-même, les boucles (`insideLoop`) et les hôtes ouverts, l'import les oublie (`readInside`). Rendu (`createInside`) : tranchée selon la profondeur de l'hôte de même copie — au-dessus devant lui, dans l'épaisseur vue par l'ouverture d'un anneau seule (invisible dans un plein), en dessous derrière lui — et dessinée juste après l'hôte ; elle-même ne cache rien. Hôte ouvert (ruban de spirale) : pas d'intérieur, seules ses parois devant le pied de la forme la cachent (`sheet` dans `plane.js`). Panneau : `ui/inside-field.js`, visible si le calque est en 3D ou porte déjà un lien ; arbre : `.inside-branch` pointillée sous l'hôte.
- Booléens : `element.booleans = [{ with, op }]`, pile appliquée dans l'ordre (`union`/`subtract`/`intersect`), `with` = autre forme du même calque (l'outil, non dessiné). Rendu par masques emboîtés (`createBoolean` dans `renderer-svg.js`), chaque copie avec la copie de l'outil de même rang (`child.copy`).
- Nom de forme (depuis `@28`) : `element.name` optionnel (`renameElement`, borné par `MAX_NAME_LENGTH`, vide = retiré) ; sans lui, libellé type + rang (`shapeName`). Renommage en place calques et formes : `inlineRename` dans `ui/list.js` (double-clic ou F2, Entrée/blur valide, Échap annule).
- IDs préfixés `L`/`E`/`I` ; `reserveIds` après chargement pour éviter les collisions.
- Commentaires `ponytail:` = simplification délibérée avec son plafond (ex. pas de mémoïsation de `getRenderedChildren`).
