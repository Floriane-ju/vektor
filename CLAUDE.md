# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Projet

Vektor (ex-Illu) : outil web d'illustration vectorielle générative (esprit « Retro Futuristic Elements »). On compose des formes sur des calques ; chaque calque porte une pile de modificateurs (pas, miroirs, axial, spirale) qui le duplique, et une pile d'interpolations qui fait varier opacité/échelle le long des copies. Export SVG, sauvegarde JSON.

Écarts avec le brief initial — ce qui fait foi est le code :
- **Pas de p5.js.** Rendu en SVG DOM direct (`#stage` dans `index.html`). Un seul moteur de rendu : le `<svg>` à l'écran est à la fois l'aperçu et la source de l'export, il n'y a pas de `renderer-canvas.js`.
- **Plusieurs modificateurs par calque** (`layer.modifiers[]`, empilés), plusieurs formes par calque (`layer.elements[]`), interpolations empilées (`layer.interpolations[]`). Une forme porte aussi les siennes (`element.modifiers[]`, `element.interpolations[]`, depuis `@25`), cumulées avec celles du calque.
- Vanilla JS (ES modules), Vite, Vitest. Interface et commentaires en français.
- **Navigateurs cibles : Chromium et Firefox.** Pas de CSS ou d'API propre à Chromium sans repli équivalent dans Firefox (ex. `interpolate-size` : largeur mesurée en JS et passée en variable CSS, cf. onglets de dessins).

## Commandes

`pnpm` uniquement (scripts de cycle de vie bloqués, cf. `pnpm-workspace.yaml`).

```sh
pnpm dev                          # Vite sur http://localhost:5173
pnpm build                        # dist/
pnpm test                         # vitest run (tout)
pnpm test test/core.test.js       # un fichier
pnpm test -t "axial"              # tests dont le nom contient « axial »
```

Pas de linter ni de formateur configuré.

## Architecture

Flux unidirectionnel : **transition pure → store → render**.

- `src/scene.js` — modèle + **toutes les transitions**, immuables, signature `(scene, ...args) -> scene`. Renvoyer la même référence = geste sans effet, le store ne notifie pas. Point d'entrée du modèle : ré-exporte `src/model.js` (sources uniques `SHAPES`, `RANGE_BOUNDS`, `STAGE`, bornes `clamp*` et valeurs par défaut) et `src/rendered.js` (`getRenderedChildren(layer)`, `copyTotal`, points reliés) — importer depuis `scene.js`.
- `src/store.js` — store minimal ; l'UI appelle `store.apply(transition, ...args)`, jamais de mutation ni de type d'action. Porte l'historique (pile de scènes, `HISTORY_LIMIT`) : un changement de sélection seule n'y entre pas, `begin(key)`/`end(key)` regroupent un geste continu en un pas — câblés au niveau du document dans `ui/history.js` (pointerdown→pointerup, input→change).
- `src/modifiers.js` — un modificateur transforme **un point** `(point, i, n, center, options) -> {x, y, angle, flip}`, appliqué au calque entier (le motif bouge en bloc). `angle`/`flip` = orientation de la copie, composée dans `applyStack` si `orients(modifier)` (case « Orienter les copies », défaut actif sur miroirs/axial/spirale), puis ajoutée à la rotation propre dans `getRenderedChildren`. Les transformations doivent rester des similitudes, sinon le motif se disloque copie après copie. Pile = produit cartésien des indices (`stackCopies`), appliquée dans l'ordre (`applyStack`) — l'ordre change le dessin. `FIXED_COPIES` : miroirs = 2 copies, `none` = 1. Spirale : `evenSpacing` (depuis `@29`) = même spirale logarithmique parcourue à pas d'arc constant (facteur `1 + i·r`, `evenTurn`), sinon pas angulaire et facteur constants (`growingTurn`). Spirale d'Archimède (`archimedes`, depuis `@30`) : mêmes réglages, facteur `1 + i·r` (`linearTurn`), `evenSpacing` = pas d'arc constant par dichotomie sur la longueur d'arc (`evenLinearTurn`). Axe d'un miroir : `modifier.axis` (degrés, `clampAxis` → [0, 180)) sinon `MIRROR_AXIS` du type (mirrorH 90°, mirrorV 0°) ; changer de type le retire. Pivot : `modifier.center` (optionnel, types de `PIVOTING`) sinon `layer.center`, y compris pour un étage de forme — `pivotOf(layer, index, owner = layer)` dans `scene.js` est la source unique (rendu des repères, glisser via `data-pivot` (`ui/gestures.js`) + `data-pivot-owner` pour un étage de forme, panneau).
- Piles de forme : appliquées **avant** celles du calque (`applyStack` chaîne l'orientation), copies = produit ; `copyTotal(layer)` = copies du calque × Σ copies propres des formes, borné par `MAX_COPIES` (`isSuspended`). Enfant rendu : `copy` (rang calque) et `own` (rang propre) ; booléens s'apparient sur les deux, repli sur `own = 0` (`renderer-svg.js`). Les transitions de pile (`addModifier`, `updateInterpolation`…) prennent l'id d'un calque **ou** d'une forme (`mapOwner`). UI : `ui/modifier-section.js` et `ui/interpolation-section.js` montés deux fois (calque, forme) avec un `ownerOf`, briques DOM dans `ui/fields.js`.
- `src/math.js` — module feuille des petits calculs partagés (`radians`, `clamp`, `wrapAngle`, `boundsOf` sans étalement) ; `plane.js` porte ceux des copies rendues (`placer` : reflet puis rotation propre, `extrusionOf`, `outlinePath`, source de `childBounds`).
- `src/interpolate.js` — rampe `t(i, n)` partagée (garde n ≤ 1 → 0, seul endroit), `clampCount` (n ≥ 1). Deux interpolations de la même propriété se composent **par produit** (neutre = 1), sauf les propriétés `additive` de `RANGE_BOUNDS` (rotation : somme, neutre 0) et `color` (plage de deux `#rrggbb`, `lerpColor`, la dernière de la pile l'emporte ; remplace la couleur de la forme sur trait et aplat). L'épaisseur interpolée est un facteur de celle de la forme ; `scaleX`/`scaleY` (depuis `@27`) étirent `rx`/`ry` et les sommets d'un tracé dans le repère de la forme (`stretch`, polygone/arc ne lisent que `rx`) ; `dashOffset` (additive) = `stroke-dashoffset` en multiples de l'épaisseur × échelle. Courbe `random` (depuis `@27`) : bruit haché `noise(i, seed)`, graine `interpolation.seed` tirée par l'UI (`randomSeed`, bouton « Relancer »), transitions pures. `binding` = rang d'un modificateur de la pile de son propriétaire (la rampe ne suit que cet étage) ou `null` (rampe sur le total des copies de cette pile). Interpolations de forme composées après celles du calque (la couleur de la forme l'emporte). Réordonner/supprimer un modificateur doit remapper les bindings (`remapBindings` dans `scene.js`).
- `src/renderer-svg.js` — `render(scene, svgRoot)` incrémental : chaque calque (`drawLayer`, depuis `getRenderedChildren`) est retenu par `<svg>` tant que sa référence ne change pas ; `scene.layers` inchangé (sélection seule) → seule la couche d'écran est refaite ; l'occlusion 3D entre calques est déballée puis refaite à chaque dessin. Couche d'écran : les repères (`data-guides`) du calque actif et le cadre pointillé de sélection (`data-selection` : boîte de la copie source de la forme, ou de tout le calque sans forme sélectionnée ; `childBounds` la calcule sans `getBBox` ; point relié = le point, pas sa chaîne ; saisissable dans toute sa surface, `data-grab`, et son survol atténue le dessin à 80 % en reprenant par-dessus la copie d'origine `data-origin` — `showOrigin`), et sur une forme seule (ni point, ni calque verrouillé) ses poignées `data-transform` (`data-resize` côté/coin, `data-rotate`) — geste `transformGesture` dans `ui/gestures.js`, repère de la forme, patch pur `scaledPatch`). `toSvgDocument` clone le DOM et retire repères/survol pour l'export. La couche d'écran (repères, cadres, poignées, survol) vit dans `src/renderer-screen.js`, ré-exportée par `renderer-svg.js` pour ses entrées publiques.
- `src/persistence.js` — `serialize`/`deserialize` + autosave localStorage (debouncée dans `main.js`). Format versionné (`FORMAT = 'vektor/scene@N'`, anciens `illu/scene@N` jusqu'à `@16`) : **tout changement du modèle** doit bumper le format et garder les anciens lisibles (`READABLE_FORMATS` + lecture legacy), import validé et borné champ par champ. `STORAGE_KEY` (`illu:scene:v1`) et `illu/settings` gardent l'ancien nom, exprès.
- Onglets de dessins (`ui/drawing-tabs.js`, pastille à droite du logo) : un document par onglet, un seul store — `store.swap({ state, past, future })` échange scène et historique (historiques en mémoire, non sauvegardés). Liste dans `illu/drawings` (`loadDrawings`, validée) ; scène par onglet sous `sceneKey(id)` (`D1` = `STORAGE_KEY` historique, sinon `illu:scene:v1:<id>`) ; `main.js` vide l'autosave avant l'échange et n'écrit dans la clé du dessin ouvert qu'après modification.
- `src/ui/*` — interface « design E » (panneaux flottants sur le plan plein écran : arbre calques → formes à gauche, réglages du calque OU de la forme à droite, outils en bas) ; panneaux DOM montés par `main.js` (`mount*({ store, container, ... })`), qui s'abonnent au store. Helpers communs dans `ui/list.js` (reconstruction en gardant le focus, `whenChanged`) ; contrôles de formulaire (`bindControl`, `segmented`, `slider`, `field`…) dans `ui/fields.js`, seul module du genre. Panneau de droite = `property-panel.js` qui assemble `shape-fields.js`, `stroke-fields.js`, `plane-fields.js` et les sections. Toolbar : gestes au pointeur dans `ui/gestures.js` (un geste = `{ move, end, cancel }`, un seul à la fois), menu Exporter dans `ui/export-menu.js`. Micro-animations (CSS seul, fin de `style.css`) : les listes reconstruites (onglets, arbre, formes, piles répéter/interpolations/booléens) passent leurs nœuds à `presence()` (`ui/list.js`) une fois en place : `data-enter` sur les lignes apparues, et chaque ligne disparue remise à sa place en fantôme inerte `data-leave` qui s'efface puis se retire (tout chemin : bouton, Suppr, ⌘Z ; liste remplacée ou autre propriétaire = rien). Étages et booléens, sans id, ont des clés par référence (`stableKeys`) ; `stateFade` pose `data-was` (ancien état de sélection) pour un fondu de couleur. La liste des formes est logée dans un pli `.layer-fold` (grid 0fr↔1fr) : changer de calque ouvre le nouveau et replie une copie inerte de l'ancienne liste — d'où l'arbre abonné **avant** la liste des formes dans `main.js`. Styles de la liste par la classe `.shape-list` (la copie n'a pas l'id) ; case « Animations » des Paramètres (`motion` dans `illu/settings`, sinon `prefers-reduced-motion`) → `html[data-motion="off"]` coupe animations et transitions (RGAA 13.8). Le plan SVG ne s'anime pas. Sections repliables (`collapsible` dans `ui/fields.js`) : état par clé (`repeat`, `interpolations`, `booleans`) partagé calque/forme, dans `illu/settings.collapsed` (seau lu et réécrit par fusion dans `persistence.js` : `readSettings`/`writeSettings`, `loadCollapsed`/`saveCollapsed`). Bouton pilule des barres : `pillButton` (`ui/fields.js`).
- **Icônes : typo Material Symbols Rounded obligatoire** (`public/fonts/material-symbols-rounded.ttf`, `@font-face` en tête de `style.css`, graisse 200 = `--weight-icon`, 16 px minimum : `ICON_SIZE.md`, dessin mis à la taille nominale par `--icon-ink`), toujours via `icon(name, size)` de `ui/icons.js` (nom interne → ligature dans `SYMBOLS` ; `iconButton({ icon })` pour les boutons de ligne). **Interdit** : une icône en ASCII/Unicode (`×`, `+`, `−`, `↑`, `⚙`, `⧉`, `?`…) ou un nouveau SVG maison. Seuls sur mesure : pictos des outils de forme (`PATHS`) et aperçus de la liste des formes (`shapePreview`). Les touches citées dans un texte (raccourcis, `title`) restent du texte.
- Polices toujours livrées dans `public/fonts/` avec `@font-face` (IBM Plex Sans, Material Symbols) : jamais une police seulement installée sur la machine, Firefox la bloque (protection contre le pistage).
- `style.css` — tokens dans `:root` (couleurs, `--space-1…9`, hauteurs `--control*`/`--row-h`/`--tool`, rayons, tailles et graisses de police, durées, échelles, opacités, `--hairline`, `--focus-ring`) ; hors `:root`, pas de px d'espacement, de durée ni de graisse bruts (`test/style.test.js` y veille). Gouttières dérivées des largeurs de panneau, en `@property <length>` parce que `ui/zoom.js` les lit en px. Chrome SVG d'écran : couleurs du thème posées en `style` (`CHROME` dans `renderer-svg.js`), jamais en attribut (un attribut de présentation ne lit pas `var()`). État d'un nœud : ARIA pour ce qu'annonce un lecteur d'écran (`aria-pressed`, `aria-expanded`), `data-*` pour l'état d'exécution (de présence de préférence, `data-in-selection`, `data-mixed`… ; valeurs quand il y en a plusieurs, `data-selected="layer|parent"`), `is-*` pour les variantes fixes d'un composant (`is-primary`, `is-danger`). Lignes d'arbre partagées calques/formes : `.tree-item > .tree-row > .tree-name`, renommage `.rename-input`.

Conventions du modèle :
- Style (couleur `stroke`, `strokeWidth`) sur la **forme** (depuis `@20` ; avant, sur le calque — relu en le recopiant sur chaque forme). Une nouvelle forme reprend `filled`/`stroke`/`strokeWidth` de la forme active ; sans forme active, `stroke`/`strokeWidth` viennent du style courant `scene.style` (carte du trait, `setStyle`/`currentStyle`, non sauvegardé, hors historique), `filled` de la dernière du calque (`addElement`). `filled` = rempli de la couleur de la forme ; style de trait `dash` (multiples de l’épaisseur × échelle de la copie), `linecap`. Contour double (`outlined`, `gap`, depuis `@22`) : trait élargi à `2·strokeWidth + gap·échelle de la copie` évidé par un masque (`hollowStroke`), sauf le point.
- Plan 3D (depuis `@23`) : `layer.plane` = `null` (jamais activé) ou `{ enabled, tilt, heading, sides }` — éteint, il garde ses réglages ; lire le plan effectif par `activePlane(layer)`, bascule `togglePlane` (cube dans l'arbre), appliqué **après** la pile de modificateurs, projection orthographique autour du centre de la scène (`src/plane.js` : `planeMatrix`, `unproject` pour le pointeur dans `toolbar.js`). La première activation (`DEFAULT_PLANE` 45°/45°) donne `DEFAULT_DEPTH` (80) aux formes sans profondeur, et `addElement` aux nouvelles formes d'un calque en 3D. `element.height` (≥ 0, « Profondeur ») = extrusion le long de la normale, centrée sur le plan. **Profondeur réelle dans un calque** (depuis `@33`, `src/hidden.js`) : toutes les copies d'un calque 3D passent ensemble par `drawPlane` (`src/renderer-plane.js`) → `hiddenLines` : chaque copie devient faces planes (haut, bas, une paroi par segment ; `meshOf`) et chaînes d'arêtes (contours haut/bas, flancs aux sommets de `silhouette` et aux coins, axe d'un point) ; profondeur exacte `u·sin(tilt) + h·cos(tilt)` (projection parallèle, un seul plan) ; chaque segment perd ce qu'une face couvre à l'écran en étant plus près — l'ordre des formes ne compte plus, ce qui est dans un volume est dedans (l'axe dans un anneau : caché dans la matière, vu par le trou). Aplats triés face par face du plus loin au plus proche (peintre, face du bas jamais peinte) ; `sides: 'filled'` peint les parois de la couleur du trait. Bloc `<g data-plane>` : `[data-fills]` puis un `<g data-element-id>` par copie (contours au style de la forme, flancs à bout rond). « Opaque » (`element.opaque`, défaut vrai, depuis `@31`) éteint = fil de fer : ses faces ne cachent rien, pas même ses propres arêtes. Contour double fermé = anneau : ses deux traits décalés dans le repère du plan (`planeDouble`), faces trouées pair-impair et parois des deux bords ; contour double ouvert = bande entre ses deux traits (`planeBand`, débouclés par `untangle`) ; tracé ouvert extrudé = feuille (parois seules). Booléen dans un calque 3D : contour réel calculé dans le plan (`booleanPieces`, `polygon-clipping`), tracé fermé par morceau, contour double compris (bords = même booléen sur les formes décalées, `rims`, pas le décalage du contour fusionné qui boucle aux jonctions) ; résultat troué ou contour ouvert → à plat par masques, dessiné avant le bloc, hors profondeur (comme l'aplat des recoupements creux). **Entre calques**, l'ordre de l'arbre reste la règle : le bloc d'un calque 3D masque les calques du dessous par la silhouette de ses volumes fermés opaques (`occluder` dans `plane.js`, trou d'un anneau rouvert) — masques chaînés dans `<defs>` (`occlude`). Hors plan 3D, `createNode` (qui émet aussi le `<path>` projeté d'un booléen à plat en 3D, `createPlaneDouble`).
- Répétition linéaire (depuis `@24`, pile du point depuis `@25`) : portée par l'étage, pas par le point : un point est remplacé par un tracé `polyline` reliant ses copies le long des étages `modifier.linear` de **sa propre** pile (l'axial se referme) — `linkPoints` dans `scene.js`. `modifier.smooth` (depuis `@26`) : tracé qui suit la transformation exacte de l’étage à indice fractionnaire (`sweep`, arc de spirale/cercle exact passant par les copies), reste une `polyline` pour le 3D/contour double. Les étages du calque ne relient jamais (`linear` retiré à la lecture), chaque copie du calque porte ses tracés. Plus de `element.linear` (ignoré à la lecture).
- `x, y` = centre de la forme, `rx, ry` = demi-extensions (signées seulement pour `line`, via `clampExtent`). Le « point » est une ligne de longueur nulle à bout rond, dimensionné par l'épaisseur.
- Le tracé (`polyline`) porte `points` relatifs à `x, y`, recentré sur sa boîte englobante (`recenterTrace`) après chaque geste. Import collé par `src/path.js` (courbes C/S/Q/T/A échantillonnées en sommets, borné par `MAX_POINTS`). Poignées de sommets (`data-handles`) = état d'écran, retirées à l'export comme les repères.
- Booléens : `element.booleans = [{ with, op }]`, pile appliquée dans l'ordre (`union`/`subtract`/`intersect`), `with` = autre forme du même calque (l'outil, non dessiné). Formes fermées seulement (`isClosedShape` : ni point, ni ligne, ni tracé/arc ouverts), hôte comme outil ; ouvrir une forme (`updateElement`) la retire des piles, la lecture aussi. Rendu par masques emboîtés (`createBoolean` dans `renderer-svg.js`), chaque copie avec la copie de l'outil de même rang (`child.copy`). À contour double, en 2D aussi : vrai contour (`booleanPieces`), un seul contour double continu autour du résultat.
- Nom de forme (depuis `@28`) : `element.name` optionnel (`renameElement`, borné par `MAX_NAME_LENGTH`, vide = retiré) ; sans lui, libellé type + rang (`shapeName`). Renommage en place calques et formes : `inlineRename` dans `ui/list.js` (double-clic ou F2, Entrée/blur valide, Échap annule).
- Forme masquée (depuis `@32`) : `element.hidden: true` (absent sinon, `toggleElementVisibility`, œil dans l'arbre) ; traitée comme un outil booléen au rendu — pas dessinée, reste outil.
- Calque verrouillé (depuis `@34`) : `layer.locked: true` (absent sinon, `toggleLock`, cadenas dans l'arbre) ; ses formes ne se saisissent plus au plan (`isLockedElement` dans `ui/gestures.js`), on n'y dessine plus, Suppr/flèches sans effet, panneau de droite en `fieldset` désactivé.
- Sélection multiple : `scene.selection` (ids, état d'écran non sauvegardé, un seul calque) ne compte que s'il contient `activeElementId` — lire par `selectedIds(scene)`, poser par `selectElements`/`toggleSelected` ; une transition qui active une autre forme ramène la sélection à elle seule. Groupe : `translateElements`, `duplicateElements` (booléens/hôtes internes suivent les copies), `removeElements`. Curseur : glisser une forme déplace la sélection, Maj+clic bascule (dans l'arbre : ⌘/Ctrl+clic bascule, Maj+clic ajoute la plage depuis la forme active, `selectRange`), glisser dans le vide = lasso sur le calque actif (`elementsInBox`, boîtes des copies sources). Carte du trait : `setStyle` règle toute la sélection, `mixedStyle` → « multi » si couleur/épaisseur diffèrent. Le reste du panneau de droite n'édite que la forme active.
- IDs préfixés `L`/`E`/`I` ; `reserveIds` après chargement pour éviter les collisions.
- Commentaires `ponytail:` = simplification délibérée avec son plafond (ex. compteur d'ids de masques jamais remis à zéro).
